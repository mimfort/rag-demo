# Внутренний регламент команды «Сапсан-7»

> Этот документ — фикция для проверки RAG. Все названия выдуманы.
> Содержит уникальные факты, которых нет в обучении LLM,
> что позволяет точно проверить: ответ пришёл из базы или из общих знаний.

## Общая информация

Команда **«Сапсан-7»** — внутреннее подразделение компании *Орбит-Информ*,
отвечающее за разработку платформы **Меридиан-Лайт** (ML-платформа для
автоматизации согласования закупок). Команда была основана 14 марта 2023 года.

Текущий состав на 2026 год — **11 человек**:

- Тимлид: **Игнат Скоробогатов** (присоединился в первом квартале 2023).
- Архитектор: **Лариса Перевертайло** (отвечает за общий дизайн платформы).
- 4 backend-разработчика, 2 frontend-разработчика, 1 QA, 1 SRE, 1 продукт-менеджер.

Офис команды находится в корпусе **Б-12**, на четвёртом этаже,
рядом с переговорной комнатой «Гнездо».

## Платформа Меридиан-Лайт

Меридиан-Лайт состоит из трёх логических контуров:

1. **Кречет** — оркестратор согласований. Хранит маршруты согласования,
   ведёт state-машину каждой заявки. Реализован на Go 1.23, использует
   PostgreSQL 16 как основное хранилище и Redis 7 для блокировок.
2. **Сокол** — UI-уровень. SPA на TypeScript + Vue 3.4. Общается с
   Кречетом по gRPC через прокси-слой **Беркут-API** (Go).
3. **Сапсан-Эдж** — пограничный сервис интеграций с внешними системами
   (СБИС, 1С:ЕРП, тендерные площадки). Python 3.12, asyncio.

Все три контура деплоятся в Kubernetes-кластер **К-Прайм** (12 нод, AMD EPYC).
Стенд для разработки называется **К-Песочница** (6 нод, виртуалки в облаке).

## Правила code review

Команда «Сапсан-7» придерживается **правила двух апрувов**:
любая PR в основную ветку требует двух явных approve'ов от членов команды,
причём хотя бы один — от backend-инженера, даже если PR чисто фронтовый.
Это правило ввели после **инцидента «Тёмный декабрь»** в 2024 году,
когда сломанная фронтовая валидация форм пропустила некорректные
заявки и потребовала ручного исправления 1827 записей в БД.

Code review проводят в Gerrit (исторически), миграция на GitHub Pull
Requests запланирована на третий квартал 2026 года под куратор-ством
**Артёма Низовцева**.

## Production-инциденты

Серьёзные инциденты команды нумеруются префиксом `СПИ-` (Сапсан-инцидент):

- **СПИ-018** (январь 2025): Падение Беркут-API из-за утечки goroutine
  при обработке cancellation. Длительность downtime — 47 минут.
  Постмортем хранится в Confluence в пространстве `S7-PM`.
- **СПИ-024** (август 2025): Деградация PostgreSQL после неудачного
  vacuum-full на таблице `approval_history` (объём ~340 ГБ).
  Решение: переход на pg_repack, добавление еженедельной задачи.
- **СПИ-027** (февраль 2026, текущий): Расследование пиковых задержек
  в Сапсан-Эдж при работе с одним из тендерных API.
  Owner: **Виктория Самусенко**, deadline для отчёта — 12 июня 2026.

## Релизный цикл

Команда выпускает новую версию Меридиан-Лайт **раз в две недели**,
по средам. Цикл называется «гнездование»: понедельник-вторник — финальный
прогон тестов, среда — выкатка на прод (окно 10:00–11:30 МСК), четверг —
наблюдение за метриками, пятница — ретроспектива и планирование.

Версионирование — semver, с дополнительным суффиксом квартала:
например, текущий релиз `4.7.1-Q2-2026`.

## Технический долг

Top-3 пунктов техдолга команды на текущий квартал:

1. **Переезд с RabbitMQ на NATS JetStream** — основная боль команды,
   планируется на четвёртый квартал. Оценка: 6 недель на полный переход.
2. **Замена кастомного auth-middleware** в Беркут-API на готовое
   решение `go-oidc`. Текущий код был написан стажёром Алексеем в 2023
   и содержит несколько подозрительных race conditions.
3. **Расщепление таблицы `approval_history`** на партиционированные
   подтаблицы по месяцам — снимет нагрузку на vacuum.

## Странные факты

- Внутренний bot в Slack команды зовут **Беркут-Бот**. Он умеет
  рассказывать состояние стенда, статистику по PR'ам за неделю и
  случайные цитаты из «Властелина Колец».
- Каждый понедельник в 11:00 МСК команда проводит **стендап «Перья»** —
  обсуждение блокеров и фокус-задач недели. Длительность ограничена 15
  минутами, опаздавшие приносят кофе.
- Любимая отладочная фраза тимлида: «Это не баг, это эмерджентное
  свойство». Команда печатает эту фразу на стикерах и клеит на ноутбуки.
